# AI Education Teachers Conclave — STEMpedia

A landing page for STEMpedia's 3-day AI Education Teachers Conclave, designed for Indian school educators. Built with HTML, CSS, and JavaScript.

## Tech Stack

- HTML5
- CSS3 (Custom properties, Grid, Flexbox)
- Vanilla JavaScript
- Deployed on Vercel

## Features

- Responsive design
- Interactive agenda tabs (Day 1, 2, 3)
- Smooth scrolling navigation
- FAQ accordion
- Block-shaped signature design motif

## Deployment

Live at: [https://ai-event-conclave.vercel.app](https://ai-event-conclave.vercel.app)
